# TUSUR Contest Helper

Локальное приложение для анализа конкурсных списков магистратуры ТУСУР по очной форме.

## Запуск

```bash
npm start
```

Откройте страницу:

```text
http://localhost:3000
```

## Как пользоваться

1. При первом открытии укажите свой уникальный код и текущее направление.
2. Нажмите `Обновить кеш`, чтобы приложение прошло по всем конкурсным спискам и сохранило данные в `.cache/contest-cache.json`.
3. Выберите направление. Таблица покажет абитуриентов из этого списка и все другие направления, найденные по их уникальному коду.

По умолчанию включен фильтр: показываются только абитуриенты, у которых на выбранном направлении приоритет больше 1.
